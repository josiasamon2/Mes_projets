# Vigie.com

Vigie.com est un petit site en français consacré à la prévention du phishing et au piratage de comptes. Il fonctionne sans installation ni dépendance.

## Les trois pages

- `index.html` — analyse locale d’une URL et repérage d’indices suspects.
- `prevention.html` — gestes simples pour mieux protéger ses comptes et appareils.
- `incident.html` — premières démarches si un compte semble compromis.
- `styles.css` — styles partagés entre les pages.

Ouvrez `index.html` dans un navigateur ou publiez les fichiers sur un hébergement statique.

## Limites de l’analyse

Le vérificateur examine uniquement des caractéristiques visibles de l’adresse. Il ne visite pas le site, ne suit pas les redirections et ne consulte pas de base de réputation ou de menaces. Son résultat est une estimation : un score bas ne garantit pas qu’un site est sûr.

## Publication avec GitHub Pages

Ajoutez les fichiers HTML et CSS à un dépôt GitHub. Dans **Settings → Pages**, choisissez **Deploy from a branch**, la branche qui contient le site (par exemple `main`) et le dossier `/ (root)`. Après le déploiement, GitHub affiche l’adresse publique du site dans les réglages Pages.

## Références de conseils

Les pages de prévention et de réaction renvoient vers des ressources publiques de Cybermalveillance.gouv.fr et de la CISA. Les démarches précises varient selon le pays et le service utilisé.
