Un doute sur un lien ?

Vérifiez avant de cliquer.

Collez une adresse web pour repérer des signes fréquents d’hameçonnage. L’analyse se fait dans votre navigateur.

Ne collez pas de mot de passe ni de code reçu par SMS.

Regardez le vrai domaine

Dans banque.exemple.com, le site appartient à exemple.com. Les mots placés avant ne prouvent rien.

Méfiez-vous de l’urgence

Un compte bloqué ou un paiement à confirmer peut servir à vous faire agir trop vite.

En cas de doute

Ouvrez le site depuis vos favoris ou tapez vous-même son adresse officielle.

Vigie donne une estimation à partir de caractéristiques visibles de l’adresse. Un résultat rassurant ne garantit pas qu’un site est sûr. Cette version ne visite pas le site et ne vérifie pas les bases de données de menaces.
